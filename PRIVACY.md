# Privacy Policy

VideoCreator, displayed on the device as **Studio**, sends only the prompt, selected reference image or media URL, and configured API key to the selected MiniMax or Qwen (DashScope) API service. It does not upload, store, or share any other user data.

Generated results and generation parameters are stored locally on the device. Platform API keys are encrypted using AndroidKeyStore and stored in DataStore.

This project is not affiliated with or endorsed by MiniMax.
